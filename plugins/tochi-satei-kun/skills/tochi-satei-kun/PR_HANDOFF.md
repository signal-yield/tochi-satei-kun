## 1. プロジェクト概要（30秒ピッチ）

**土地価格査定クン**は係数全開示型の OSS（オープンソース）AVM。土地の査定価格を、ヘドニック回帰係数を **全開示** した「白箱方式」で出力する Claude Cowork スキル。

- 係数全開示型の OSS AVM として GitHub 公開（Apache 2.0 ライセンス）
- 不動産鑑定士（個人）発の OSS、白箱方式の提案
- 「AVM 界の Linux」がメインタグライン

## 3. 訴求軸 3つ（PR Times 原稿の柱）

### 軸 1: 「OSS であること自体が革新」
- 係数全開示型の OSS AVM として GitHub に公開（Apache 2.0 ライセンス）
- GitHub に置いた瞬間、誰でもコードを読める＝鑑定士・媒介担当者が「なぜこの査定価格か」を完全に説明できる
- 「実装の難しさ」ではなく「公開する決断」が革新
- Apache 2.0 = 特許保護条項付き、企業導入時の法務障壁を下げる設計

### 軸 2: 「都度回帰の白箱方式」
- ヘドニック係数 β は **物件ごとに都度回帰**（市区町村ごとに過去 5 年のデータから毎回算定）
- 全 12 特徴量の係数・p 値・標準誤差・自由度調整済 R² を業者用シートに開示
- 査定根拠を計算式まで遡って説明・検証できる透明性

### 軸 3: 「鑑定実務との接続」
- 不動産鑑定士（松田氏）が監修した鑑定書様式の比準表
- 業者用は鑑定書の「2 行式」（事情補正 / 時点修正 / 標準化補正 / 地域格差）
- 顧客用は流推方式準拠の机上査定書
- OSS として開放することで、業界の査定品質底上げ・教育・監査用途への展開を可能に

## 4. 6 つの特徴（PR Times の特徴紹介として使う）

🚨 **旧版にあった他社 AVM との比較表は削除しました**（v1.4.0、対外発信で他社 AVM への名指し・暗示比較を一切しない方針）。代わりに以下の **単独主張型** の特徴テーブルを使ってください。README にも同内容が掲載されています。

| # | Feature | 説明 |
|---|---|---|
| 01 | **オープンソース（Apache 2.0 License）** | GitHub に公開。ソースコード・ヘドニック回帰係数・補正率も全部開示。商用利用・改変・教育用途すべて自由 |
| 02 | **査定根拠を「すべて」開示** | ヘドニック回帰の係数（β・p 値・標準誤差）と、比準表の内訳（採用事例の選定理由・補正率・試算値）を業者用シートに全部収録 |
| 03 | **市区町村単位で都度回帰** | 全国一律の固定値ではなく、市区町村ごとに過去 5 年の取引データから毎回係数を算定 |
| 04 | **検証・監査・教育研究すべてに対応** | コード・係数・補正率すべてが公開のため、第三者検証・社内監査・学術研究にそのまま使える |
| 05 | **業者用＋顧客用 2 シート構成 xlsx** | 業者用シート（係数全開示）と顧客用シート（流推方式準拠で売主提示用に整形）の 2 シートを一括生成 |
| 06 | **完全無料・追加費用なし** | Claude の契約料以外に追加費用は一切なし。業者・不動産鑑定士・銀行不動産担当・教育機関すべての方が自由に利用可能 |

| 質問 | 回答 |
|---|---|
| **マンションは？** | 対象外。建物評価が必要なため別ツールが適切 |

| **海外展開は？** | 当面なし。日本の MLIT データ・地価公示に特化している |

## 14. v1.4.0 アップデート（2026-05-17）— **必読**

v1.2.0 → v1.4.0 で大きく変わった点と、PR 原稿への反映方針。

### 🔴 ライセンス変更（最重要）

- 訴求材料として PR 文に必ず反映:
  - 「**Apache 2.0 ライセンス**」「**特許保護条項付き OSS**」
  - 「TensorFlow / Kubernetes と同じ業界標準ライセンス」

### 🔴 バージョン表記

- v1.2.0 → **v1.4.0**
- すべての PR 文・SNS 投稿・LP で表記更新必須

### 🔴 競合言及禁止（最重要）

このハンドオフメモの旧版には他社 AVM への名指し・暗示比較が複数箇所ありました。v1.4.0 で全削除済みです。**PR 文・SNS・LP・デモ動画など対外発信物すべてで競合 AVM への言及は一切しません。**

NG 表現例:
- ❌「〇〇社は係数を非開示だが、本プロダクトは…」（名指し）
- ❌「国内 AVM はすべてクローズド」（暗示）
- ❌「非開示方式への挑戦」（暗示）
- ❌「クローズド独占に挑む」（暗示）

OK 表現例:

1. 法的リスク回避（名誉毀損 / 不正競争防止法）
